# 节目 30s 语音素材来源

6 个组播节目各绑定一段 **30 秒真实语音**，全部由 B 站公开视频的音频轨截取，
不依赖任何外网 CDN —— 拷走 `web/` 目录、断网也能出声。

## 处理流程

```
bilibili 视频  →  取播放地址（html5 playurl 接口）  →  ffmpeg 抽音频轨
      →  按时间点截取 30s  →  响度归一 + 高通 + 限幅  →  单声道 128kbps MP3
```

统一使用的 ffmpeg 处理链：

```bash
ffmpeg -ss <起点> -t 30 -i <视频> -vn -ac 1 -ar 44100 \
  -af "loudnorm=I=-16:TP=-1.5:LRA=11,highpass=f=90,alimiter=limit=0.95" \
  -c:a libmp3lame -b:a 128k <输出>.mp3
```

截取点是用频谱 + 10ms 帧能量起伏（语音调制指数）挑的：
语音段能量起伏明显（std≈5~10dB）、谐波横纹稳定；
纯音乐段能量起伏小（std≈2dB）且充满竖条瞬态。挑点后逐段复查过频谱。

## 说明

- `BV1s7bG6nEhe`、`BV13WY467EPB` 是国家应急广播的资讯视频，属于 **纯语音播报**，
  频谱上是典型的人声谐波横纹，三段/一段都直接取用。
- `BV1Axes6wEoo` 是一首 Vocaloid 翻唱，**不是**新闻视频。
  为避免把歌曲人声当成广播节目播出去，只取它的 **器乐段**（60s、200s 起的段落），
  频谱上是横向谐波条纹 + 无语音调制，听感更接近"测试信号 / 垫乐"。
